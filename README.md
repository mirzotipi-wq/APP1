# Key & Fill

**Plan the light. Recreate the shot.**

Key & Fill is a native iOS lighting studio for photographers and independent filmmakers. Import a reference, explore plausible lighting arrangements, design a scene in 3D, place equipment in a real room using AR, and export a practical lighting plan.

**Status:** interactive prototype / pre-alpha. Source includes editable overhead plan, illustrative orbitable 3D, full-frame camera preview, a numerical direct-light sphere study with optional validated Metal compute and CPU fallback, lighting recipes, undo/redo, point/directional/rectangular emitters, manual aim/modifier dimensions, ideal lux, relative white balance/exposure, local save/reopen and shareable text. [GitHub Actions](https://github.com/mirzotipi-wq/APP1/actions/runs/45262428316) passed 58 portable Debug and Release tests, native Swift syntax parsing, generated three actual render fixtures, and six shared Float32 host parity comparisons. Apple SDK build, actual GPU execution, UI smoke and screenshots remain unverified while the macOS runner queues. The Study is not a calibrated portrait; reference inference, AR, commerce and release gates remain outstanding. The name is provisional pending trademark and App Store checks.

## Getting started

Requirements: Swift 5.9 or later for the portable domain package; macOS with Xcode supporting iOS 17+ and XcodeGen for the native app. The project file is generated, not committed.

```sh
swift test
python3 scripts/agent_cycle.py check
python3 scripts/agent_cycle.py next
# macOS only:
xcodegen generate
open KeyAndFill.xcodeproj
```

For an unsigned simulator build after generation:

```sh
xcodebuild -project KeyAndFill.xcodeproj -scheme KeyAndFill \
  -configuration Debug -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```

Use a physical supported iPhone for camera/AR and thermal tests. Do not represent simulator output as real-device evidence.
