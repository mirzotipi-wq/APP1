# Evidence ledger format

Append entries to evidence.json, preserving prior results. Required fields: gate (exact ID from state), result (pass/fail/unverified), revision (exact tested 40-char commit SHA for pass), date (ISO 8601), method (actual command or procedure), environment (hardware, OS, SDK, build config), artifact (durable path or URL), reviewer (actual identity or explicitly self-review), notes (numeric results, limitations, fixture, sample size, rationale). Record failures and missing capabilities. Last observation controls status. The checker validates structure, not authenticity, artifact existence or freshness; agents must examine evidence and invalidate affected gates after changes. Release review must audit the full ledger against the integrated revision. No synthetic user interviews or fake CI.
