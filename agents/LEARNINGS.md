Initial design decision (not a measured result): single-image lighting reconstruction is underdetermined; keep the solver output editable, communicate confidence, and validate against held-out scenes rather than claim exact inverse rendering. Treat this as a hypothesis to evaluate in M04.

2026-11-23 / M01: The local environment has Swift but no Xcode and cannot resolve github.com. Reconstruct the portable package only from fetched source, verify every Git blob SHA before attributing the result to a commit, and leave simulator gates to the macOS workflow. The full domain suite passed 11/11; review is self-review, not independent device verification.

2026-11-23 / M01: fileExists plus a metadata-only size check was an insufficient read contract: missing and unreadable must differ and actual bytes must stay bounded even if the file changes size. Replaced with explicit metadata error classification, regular-file validation and bounded reads; five regression tests pass. A UUID-scoped debug test namespace prevents stale fixtures across repeat runs. Simulator behavior is still unverified; use the actual native runner to close the gate. The private app storage model does not promise protection against concurrent external filesystem mutation.

2026-11-23 / independent M02 math: use a distinct normalized direction type and declared minimum emitter-plane distance; compare quadrature against both a closed-form parallel rectangle and a separately coded Simpson integral. Initial local compilation caught a missing try in an invalid-geometry test; corrected and reran the complete suite. No gate changes or weakening; retain raw fixture results and never extrapolate them to calibrated photographic realism.

2026-11-23 / independent M02: Versioned source optics and camera lens settings must preserve legacy scenes, including nil defaults, and reject future/invalid schemas. Eight optics and seven camera tests passed alongside all prior tests (37/37). Keep camera-forward and emitter-normal bases distinct, and treat degenerate aim and near-field as unavailable rather than silently substituting a valid geometry. Native rendering remains illustrative and unverified.

2026-11-23 / independent color: CCT does not specify a real lamp spectrum or camera response. Normalize ideal Planckian XYZ to Y=1 before lux-weighted mixing, adapt reference white before display tone mapping, and keep exposure independent of the incident-light meter. Eight tests include CIE illuminant A tolerance, matched neutrality, additive mixtures, exposure doubling, extreme valid values and migration. Avoid main-thread recomputation during slider changes; actual iPhone timing remains unverified.

2026-11-23 / M01 + independent M03: after fixing undefined addAttachment, source review found let add = app.buttons["addLight"] shadowed XCTestCase.add(_:). Rename the local and use self.add(attachment) explicitly. Prior job 137999912916 logs confirm actual undefined-method errors on an older revision; the shadowed-call defect is source-confirmed, not an observed current SDK error. Native CI remains the authority. A library must compare the loaded snapshot before replacement, not trust the selected ID alone; migration preserves legacy bytes and never falls back to old data when a newer library is corrupt. 2026-11-23 / M04 independent slice: Photos picker transfer should consume the temporary file within its FileRepresentation callback, enforce encoded byte and declared pixel bounds before decode, downsample with orientation, draw into a fresh sRGB bitmap and avoid copying source metadata. A request token and cancellation guard prevent stale async imports from replacing newer selection. The app does not retain a source URL or asset ID; iCloud retrieval belongs to the system picker. Native first-source app build passed, but actual picker and privacy/device behavior are pending. Avoid equating a successful build with permission/cancellation verification.

2026-11-23 / M04 guided alternatives: manual observations are not pixel-derived inference. Use camera-relative bases, keep the scene camera and subject, calculate assumed incident plane lux with the existing validated photometry and label arbitrary scale/temperature and fill assumptions. Six solver tests passed Debug and Release on e7332c8; they cover 108 observation combinations, 216 candidate scenes, round trips, rotated camera, bounds, lux and uncertainty. The full inference gate still requires held-out controlled photos and independent review. Descriptive tone statistics linearize sRGB before luminance and exclude partially transparent samples; source size limits, fixed 128 px thumbnail, and no interpretation of histogram as measured illumination. Latest core job 138025049210 completed successfully: 89/89 in each configuration, five tonal-summary tests passed; native simulator queued. No protected contract changed.
