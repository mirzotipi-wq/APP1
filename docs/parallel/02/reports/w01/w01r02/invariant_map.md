## Evidence boundaries

The Python probe covers seven parallel geometries (minimum area, maximum aspect ratio, minimum allowed depth and far-field), eight full/partial similarity combinations, 128 seeded general geometries, and eight grazing strips/corners. Maximum area-reference relative error: 0.0004080644185926463. This is finite case coverage, not a proof over all geometry.

The area reference uses independent vertical-slice bounds and generated 48-point Gauss-Legendre nodes. The production transcription uses explicit clipping with the source's 12-point triangle nodes, or its 32×32 midpoint convention. The parallel analytic expression supplies a third comparison.
