# W01-09 — platform/performance

Base: `f150f98e35dd735927075aac4d2f8b02295c6a67`. Static baseline review only; no new implementation inspected and no builds, tests or benchmarks run.

**Compatibility and ownership:** Preserve Swift tools 5.9, iOS 17 and native Swift 5 language mode (`Package.swift:1–10`; `project.yml:4–5,22–24`). Keep portable editor values/history independent of SwiftUI observation; `SceneEditHistory` is Foundation-only, Equatable and Sendable (`Sources/LightingCore/SceneEditHistory.swift:1–8`), consistent with `docs/ARCHITECTURE.md:6–11`. Native observation, bindings, preferences, lifecycle and existing store/operation orchestration belong in App (`App/StudioView.swift:5–53`). Make the new session explicitly `@MainActor` and initialize it from an explicitly isolated context: the app already has that annotation, while `StudioView` currently does not (`App/KeyAndFillApp.swift:3–5`; `App/StudioView.swift:4`). Do not rely on newer compiler isolation defaults.

**Window lifetime:** Preserve one editor/session per window. `WindowGroup` constructs `StudioView`; its scene, selection and history are local state. Entitlements alone are intentionally app-shared (`App/KeyAndFillApp.swift:6,14–22`; `App/StudioView.swift:9–10,27`). A single app-owned session would change existing window independence.

**Hot-path confirmation:** Full-scene validation traverses all lights and allocates an ID set; each light validates its name using trimming and character counting (`Sources/LightingCore/Scene.swift:33–36,62–80`). The 80-character bound does not bound Unicode scalar count. Current camera/subject/preview/lens setters validate only changed values (`App/StudioView.swift:1082–1120`). Thus full validation per sample adds source-identifiable work, with no measured latency claim. Also avoid extending optional normalization's nested light lookup (`Sources/LightingCore/SceneEditHistory.swift:33–56`) to every numeric edit. Root's accepted typed-mutation approach addresses this risk.

**Acceptance case — not run:** Build the unchanged iOS 17/Swift 5 target with the extracted, explicitly main-actor-isolated session initialized per `StudioView`; verify no actor-initialization error and no SwiftUI/UIKit dependency introduced into LightingCore.
