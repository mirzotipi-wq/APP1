## 1. Keep local Apply consumption distinct from parent retirement

**Observed:** Reference closes its local session before invoking `onApply`, then dismisses (`App/ReferenceComparisonView.swift:117–122,530–534`). Arrangement sets `didFinish` before its callback and dismissal (`App/SceneArrangementView.swift:97–107`); Cancel consumes it at `75–78`, but interactive dismissal has no corresponding local hook. Parent callbacks use only generation/equality (`SV:154–158,189–193,1234–1240`), despite capturing an owner (`75–80`).

**Falsification tests/inferred risk:** A delayed captured callback after dismissal/reopen B, or after scene S→T→S, passes the baseline predicate. Actual SwiftUI delivery was not reproduced. Assert stale A cannot mutate scene/history or retire B. For a legitimate Apply, child duplicate prevention must precede callback, while parent ticket acceptance/consumption remains atomic; retiring the parent ticket before that callback would reject valid Apply.

## 2. Nested manual Done must not finish the outer AR room transaction

**Observed:** Direct room Done calls `onClose` before dismissal (`App/ManualRoomPlacementView.swift:114–116`). AR's nested manual close only hides its nested presentation (`App/ARPlacementView.swift:63–90`); nested callbacks verify their own owner before forwarding (`93–105`). Outer AR Done retires the parent (`54–57`). Parent room callbacks remain repeatable, mask only room changes, and share an owner (`SV:1264–1301`); same-owner history begins retain the original scene (`Sources/LightingCore/SceneEditHistory.swift:69–86`). Manual kept/remove state changes only after a true acknowledgement (`ManualRoomPlacementView.swift:158–165,185–194`).

**Required tests:** Direct apply A→B→remove→C→Done yields one undo to the initial scene. AR manual apply A→nested Done→reopen manual→apply B→nested Done→AR Done likewise yields one undo. Nested Done must retire only nested callbacks, permitting the new nested owner to continue the outer transaction. Deliver old apply/remove/dismiss callbacks after reopen: none may mutate or terminate the new owner. Reject intervening non-room edits, including edit→undo.

**First save:** Existing save closes history before awaiting (`SV:1463–1467`), rotates generation on draft-to-project identity while preserving history (`App/ProjectLibraryOperation.swift:115–120,131–134`), then dismisses editors (`SV:1479–1485`). Preserve this with an unchanged-scene first-save regression: old tickets rejected, undo retained, fresh presentation accepted.
