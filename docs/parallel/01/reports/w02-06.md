## Actionable contract clarification

`StudioFeatureSession.dismiss()` only sets `isPresented = false`; its immutable `context.scene` remains stored (`StudioFeatureContext.swift:24–43`). **Dismissal retires callbacks; it does not itself release the snapshot.**

Document two boundaries: immediately retire the live parent-owned session, then clear its matching optional session/payload when presentation cleanup completes or the project resets. Match presentation identity before clearing so an old dismissal cannot clear a newer owner. Existing room/AR cleanup demonstrates this (`App/StudioView.swift:1283–1293`); project invalidation clears payloads at `1304–1318`.

Setting the parent’s optional to nil releases **only that ownership**. Captured contexts, closures, tasks, or independent state copies may legitimately retain snapshots until completion/release; dismissal is not proof of full deallocation. Producers may retain immutable contexts, but acceptance must consult the live parent session, never a captured session copy. This is a missing release-contract detail, **not an observed leak**.
