- **Invalid commands are atomic.** `StudioEditorState.swift:62–120` validates each payload and exact live light UUID before committing. The closed enum cannot alter identity, names, schema or count. Existing private validated-scene invariants justify omitting whole-scene revalidation; unrestricted update/replace/adopt retain it. Selection is not used to redirect a light command.
- **History and revision semantics survive.** `StudioEditorState.swift:179–186` normalizes representations before equality/history writes. Actual changes join an open edit or record one discrete change; no-ops retain revision and redo. Invalid payloads/missing UUIDs leave the complete editor unchanged. An out-and-back edit intentionally retires revision while retaining redo after closing an unchanged transaction.
- **Callbacks retain identity.** `StudioView.swift:1028–1105` captures generation and light UUID in bindings; scalar/optics commands target that UUID even after selection changes. `StudioSession.swift:166–170` derives control identity only from workspaceResetID and stable field/light strings. First save may change generation without changing that identity (`ProjectLibraryOperation.swift:115–120,131–134`); stale completion callbacks are rejected before ending editing (`StudioSession.swift:108–116`).
- **Plan ordering stays sound.** `StudioSession.swift:122–151` rejects stale/busy/unloaded/blocked, missing/unselected UUID, invalid scale and nonfinite translation before beginning history. Translation uses its frozen origin and scale. With the validated source, finite inputs and positive scale, clamped x/z plus the source y produce valid position even if division overflows. The final typed position update cannot bypass admission. Rejected reservations retain the drag; accepted reservations close it. Different-owner and old-generation endings cannot close a newer transaction.
- **Room/AR acceptance is preserved.** `StudioView.swift:1231–1267` checks room validity and live presentation/snapshot admission before opening history. An unchanged room, or removal when absent, returns true before mutation. Accepted changed room values cannot normalize back to the prior room; the typed mutation Bool therefore remains true.
