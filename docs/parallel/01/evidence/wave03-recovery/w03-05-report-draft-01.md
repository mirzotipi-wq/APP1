- **Nonblocking API boundary: repeat `.load`.** After load → edit scene → call `beginLibraryOperation(.load, from: session.generation)` again, admission succeeds and `.load` replaces the dirty scene and resets history (`174–181`; `ProjectLibraryOperation.swift:110–114`). Recommendation: explicitly admit load only before initial success or while blocked, and add a sequential duplicate-load regression. Concurrent duplicate loads already fail reservation.
