# Lane 01 observations

- Scene validation and storage adoption need separate policies: replacing content while keeping old redo or an open gesture rebases history. Reject changed no-reset adoption before any state mutation; retain the regression.
- Stable control identity and stale callback admission are different concerns. Making first-save control identity stable exposed an asymmetric View end callback. Both begin and end must use generation admission; actual session tests alone do not prove native View forwarding. Independent source review caught the adapter defect.
- A computed full-scene setter accidentally repeated imported-name/all-light validation for scalar controls. Closed typed commands should validate changed fields on an already validated editor while preserving full validation at external boundaries. Performance remains unmeasured.
- Temporary filesystems were replaced twice. Preserve source/checksums/reports remotely early, keep small source worktrees and logs in persistent workspace, and use temporary storage only for rebuildable compilers/build output. Recovered files require fresh checks; lost raw logs remain explicitly lost.
- Real capacity includes active finishing workers. A wave 3 spawn was rejected before a previous worker exited; it created no ID and received zero credit. Managers queue within actual slots and count returned IDs only.
