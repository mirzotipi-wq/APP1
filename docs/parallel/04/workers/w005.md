# w005 — cancellation/concurrency audit

Baseline `f150f98`, clean worktree. Read AGENTS, protocol, acceptance, renderer, preview, cache, and relevant tests. Source inspection only; no builds/tests/network or repository edits.

## Observed contracts

- `StudyRenderEngine.render` has no suspension points (MetalStudyRenderer.swift:175–230). Other requests cannot interleave backend selection, submissions, or cache mutation. Queued cancellation is checked at entry (178).
- Submitted GPU work finishes before buffer reads (82–87); the engine checks cancellation before retention (215). Interrupted validation leaves state unchecked for retry (199–205). Backend failure removes cached Metal frames (232–236).
- Preview cancellation guards run after the actor return and image conversion (ReferenceStudyPreview.swift:117,120). Older same-subject images carry previous/updating labels; old errors and different subjects are hidden (48–88). No concrete stale-current-image race established.

## Precise schedules and gaps

**Final-check boundary (inference, unexecuted):** last poll returns false → external cancellation → hit promotion/return (184–185), or miss retention (192/215/228→243). Actor isolation does not make a cancellation poll atomic with admission. This narrows the literal “cancelled work never enters cache” claim to cancellation observed before the final checkpoint. It does not establish wrong pixels or visible stale adoption; adding another poll only narrows the interval. Do not treat this alone as a blocker.

**GPU queue:** A commits → A cancels → B queues → A completes, reads output, then throws → B runs. Cancellation after the pre-render check can permit one obsolete submission. Existing tests do not deterministically cancel after GPU submission.

## Smallest test plans (all unrun)

1. Warm a 24-pixel bust cache. On the second injected poll, call `withUnsafeCurrentTask { $0?.cancel() }` but return false. The predicate reads `Task.isCancelled` before the callback. Assert the outcome and LRU order; repeat at a measured final miss poll, then probe cache warmth. Existing native tests265–315 cancel before polls, not during this ordering.
2. Pause A through its injected probe; enqueue/cancel B; release A. Assert B throws and a live C returns correct bytes, without assuming FIFO ordering.
3. Add a minimal post-commit test hook: cancel real GPU work after submission, assert no cached result and successful retry without permanent CPU downgrade. A hosted A→B→A, subject-switch, and background/foreground test should assert final visible request identity.

Recommendation: retain existing cancellation safeguards; resolve these deterministic coverage gaps before claiming stricter cancellation atomicity.
