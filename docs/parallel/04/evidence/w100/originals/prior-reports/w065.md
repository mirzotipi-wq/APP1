## Findings

Another render therefore cannot duplicate a successful startup. Cancellation observed at the final validation poll throws before adoption; the local backend is released and startup remains retryable. Confirmed failure selects permanent CPU before observing concurrent cancellation and selectively removes Metal entries, preserving CPU frames.

These are cooperative polling guarantees. If an external flag changes after the final validation poll, the already validated backend can be retained before the next poll rejects the request. This is neither unchecked-backend adoption nor an atomic cancellation guarantee. Cache-hit cancellation is checked before recency mutation.
