## Finding: no source-provable production test-hook defect

`App/ProjectStore.swift:10–17,25–35` conditionally declares/captures every test flag under `#if DEBUG`. The alternate library directory is separately guarded at `105–110`; corruption/full/large fixture creation at `112–146`; injected competing save at `153–162`. Consequently, when `DEBUG` is absent, none of these mutations or redirects exists. In Debug, fixtures additionally require a valid UUID, the corruption write is create-only, and populated libraries are not reseeded. Missing/invalid UUIDs still use `KeyAndFill-UITests`, never the normal directory. Relevant existing regressions are themselves Debug-only (`NativeTests/ProjectStoreOperationTests.swift:386–459`); reviewed, not rerun.

`App/StudioPreferences.swift:12–21` confines the test suite to Debug; Release returns `.standard` at `22`. No app source references `temporaryDirectory`, `removePersistentDomain`, `setPersistentDomain` or a launch-triggered defaults reset. Test storage is application-support/UUID isolation, not temporary storage. `App/KeyAndFillApp.swift:8–16`, `App/StudioSession.swift:60–69` and the preferences consumers use their ordinary production defaults; no alternate entrypoint interprets the flags.

**Release launch consequence:** `-ui-testing` and `KEYFILL_UI_*` alone cannot trigger fixture corruption, seeding, competing writes or preference resets. They also **do not isolate a Release app**: it uses normal `KeyAndFill` storage and standard preferences, so subsequently exercising ordinary save/settings actions changes that application's normal data. This is distinct from a test-hook leak; Release automation must not assume Debug isolation.

Diagnostic behavior is also compile-gated. `App/StudioTextLayoutDiagnostics.swift:15–20` returns false outside Debug; both view helpers return `self` (`77–108`) even if the internal `enabled` argument is true; the AX-value modifier itself is enclosed by `112–126`. Pure record/codec helpers and diagnostic constants remain in source outside the guard, so this review does **not** claim every diagnostic symbol/string disappears. `App/StudioSlider.swift:3–5,147–152,259–273` excludes OSLog import, logger/state and logging body, replacing `trace` with a no-op. The ordinary accessible value (`126–131`) remains intentional product behavior.

Internal dependency-injection APIs remain available, including `ProjectStore`'s directory argument, `StudioSession` executors and `ReferenceStudyPreview.renderStudy` (`App/ReferenceStudyPreview.swift:77–81`). No process flag selects them. `MetalStudyRenderer.renderValidationFixture` is intentionally used by the production numerical startup gate (`App/MetalStudyRenderer.swift:119–135,247–253`); it renders fixed validation scenes in memory and does not seed saved projects.
