## Implementation

Callback-driven, main-actor sheet with inspection, confirmation, pending, error/retry, and persistent success states. Explains that unreadable files may be damaged or from a newer app version; suggests update/retry first. Displays inspected file/byte counts and explicitly explains that originals stay on device before creating a new library, while previous projects remain unavailable. The native confirmation action is **Keep files and start again**.

Inspection tokens are invalidated on reinspection, dismissal, and failed recovery. Request identities and cancellation checks prevent cancelled/stale reads from publishing; delayed confirmation actions must match the current inspection. Stale-snapshot failures request a fresh check. Unrecognized errors do not expose paths or assert an unconfirmed outcome.

The recovery callback reserves the session task synchronously before the view observes it. The observer never cancels or ignores a committed receipt. Done is disabled during recovery, swipe dismissal is disabled, and success never dismisses automatically. Success explains Projects → Import editable project without claiming previous projects were restored. Controls have 44-point minimums, wrapping text, semantic labels/IDs, and scrollable layout; no text-size cap.

## Exact integration

```swift
// Capture generationAtPresentation when opening the sheet.
.sheet(isPresented: $showLibraryRecovery) {
    ProjectLibraryRecoveryView(
        onInspect: {
            try await session.inspectUnreadableLibrary(from: generationAtPresentation)
        },
        onRecover: { snapshot in
            try session.recoverUnreadableLibrary(snapshot, from: generationAtPresentation)
        })
}
```

Worker 013 supplies those session APIs. View callback types are `() async throws -> ProjectLibraryRecoverySnapshot` and `(ProjectLibraryRecoverySnapshot) throws -> Task<Void, Error>`. Keep the sheet binding/presentation independent of workspace or feature resets; task success must include committed session adoption. Root must add the new file to Package.swift exclusions.
