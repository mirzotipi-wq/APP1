## Result and design contract

Settings now opens **Beta feedback**, a native form for optional problem/observation, reproduction steps and expected-result notes. The user reviews a structured local report before choosing **Share report** through ShareLink/system sharing; no recipient is invented or automatic transmission added. Native labels, hints, identifiers, multiline fields and scrolling respect Dynamic Type without fixed text heights. A populated draft prevents swipe dismissal and offers an explicit discard/keep-editing confirmation. Notes use view state only; no persistence, background work, network or permissions were added.

The deterministic portable builder accepts only supplied app/build/OS versions, a typed coarse device family and explicit notes. It cannot collect scene/library/photos/log/account/network/hardware-identifier contents. The report and UI state what is included and excluded, explain that user-typed personal details are not automatically redacted, and retain honest simulation/calibration limitations.

Each note is scanned for at most 8,192 Unicode scalars plus one lookahead, then limited to 2,048 UTF-8 bytes without splitting graphemes. A potentially partial grapheme at the scan limit is omitted. The preview and shared text are identical; truncation is disclosed per field. Line endings, tabs, whitespace and hidden directional/control characters are sanitized while ordinary international scripts, joiners and emoji survive. Invalid/oversized metadata becomes `Unavailable` rather than a silently altered version. The entire report is bounded to 8,192 bytes by its fixed structure and field limits.
