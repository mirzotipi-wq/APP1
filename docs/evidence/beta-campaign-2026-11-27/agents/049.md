## Findings

**Two deterministic command counterexamples warrant repair/review; native UI occurrence remains unverified.**

1. **Retired Plan callbacks can restart and double-apply cumulative movement in the same storage generation.** In `App/StudioSession.swift:254–258`, any accepted value callback creates a new `planDrag` when nil. `replace`, a different control's begin, and an accepted save clear that drag without retiring its callback identity. Example: selected light at x=-1.5; drag +20 px at 100 px/m yields -1.3; replace only its name; replay the same old +20 px callback: accepted, x=-1.1. The marker still exists with the same UUID and selected state. `StudioPlanMarkers.swift:208–218` retains its original closure, and `:165–177` does not observe the session's Plan reset. The probe also reproduces reactivation after another control begins and after an existing project's second save, which intentionally keeps storage generation unchanged. The latter changes the just-saved scene and makes it dirty. Existing tests cover late ends after replacement and stale generations, not late values within this generation.

2. **An accepted height edit can disappear with no undo snapshot.** Fresh session: `dragLight(+20 px)`; `apply(.lightValue(id, .y, 4))` succeeds; `dragLight(+30 px)` succeeds and restores y=2.1. `StudioSession.swift:263–269` copies the complete frozen `source.position`, including y, despite Plan only controlling x/z. The field command joins the open Plan history. After finish, Undo and Redo both have y=2.1; the accepted y=4 state is absent. Exact-value bindings call this field API without an owner boundary (`StudioView.swift:977–999`). Whether an actual numeric-sheet presentation always cancels the touch before Apply needs native confirmation.

Recommendation: give each recognized Plan gesture a fresh token that remains retired after a boundary; require that token on changes and completion. Test delayed value and delayed end separately, including same light/same generation and completed existing-project save. Preserve the live unaffected y coordinate and explicitly separate unrelated discrete field commands from Plan's transaction.
