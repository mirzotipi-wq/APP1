## Repair

Added the actual form's NoteDraft state machine. It scans at most 8,193 Unicode scalars before adopting a replacement, accepts 8,192, and keeps accepted raw bytes intact. Oversized input is rejected whole; previous text and a per-field visible error remain. An unchanged native echo cannot clear the error; a changed bounded edit or explicit Keep previous text/Keep field blank action can. Review is disabled and guarded until errors resolve.

Review now freezes a report value when invoked, preventing later draft callbacks from changing the displayed/shared report. Existing report normalization, truncation notices, metadata allowlist and manual sharing remain intact. Close follows the existing precision/name editor pattern: adaptive Form header, growing body text, minimum 44-by-44 target, explicit content shape and existing accessibility identifier.
