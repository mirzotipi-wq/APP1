## Finding and implementation

Deterministic corruption previously made every normal load/save fail without a preservation-first recovery API. Existing normal-save CAS and legacy migration remain unchanged.

Added `inspectUnreadableLibrary() throws -> ProjectLibraryRecoverySnapshot` and `recoverUnreadableLibrary(_:replacing:) throws -> ProjectLibraryRecoveryResult`. The opaque, Sendable/Equatable observation exposes only `fileCount`/`byteCount`; it binds the standardized store directory, both files' presence, exact bytes, inode/volume identities and modification dates. The receipt contains the committed validated library and archive directory.

Inspection is read-only and does not trigger migration. Only decode/validation failure qualifies. Missing or valid libraries (including valid legacy scenes), nonregular files, direct directory/file symlinks and oversized input are rejected. Read/permission errors remain errors, never evidence of corruption. Existing bounds remain 8 MiB library and 1 MiB legacy. New recovery failures have fixed localized descriptions without private paths.

Recovery validates/encodes its replacement before touching storage, then compares the complete observation under the **same** transaction lock used by normal saves and migration. It preserves every observed source under `Recovery/<UUID>/` using original filenames and exact bytes, without overwriting existing evidence. Evidence files are synchronized and read back for equality. A second complete source comparison precedes the atomic library write. Legacy source bytes remain untouched; partial archives are deliberately retained if preservation or later work fails. Reused/stale observations cannot authorize another commit.
