# A076 — Save/adoption review (M02/M03)

Scoped no defect found in current `App/StudioView.swift`, `ProjectLibraryOperation.swift`, `ProjectStore.swift`, and library observers.

Reservation captures scene, expected library, project identity, and generation synchronously before launching work. Scene mutation callbacks reject busy or stale generations. Save adoption retains `currentScene` while marking only the returned persisted scene as `saved`, so later edits cannot be falsely marked saved or overwritten. First-save identity adoption preserves history/selection while invalidating stale editors. Switching/reloading deliberately resets history and changes generation.

Adoption checks request ID, generation, and project ID; `finish` cannot clear another request. Store cancellation is checked before synchronous transaction work, with no cancellation throw after commit. Sheet observers await the independently owned Studio task, and import cancellation cannot abandon a reserved commit. Failed operations retain scene/library and release their own reservation.

Static inspection only; no builds or runtime verification performed.
