# a085 — Live source guard for precision drafts

Frozen files: `App/DistanceValueButton.swift`, `App/PrecisionValueButton.swift`.

Distance editors now pass the raw SI `Binding<Double>` through the optional `underlyingValue` parameter. The editor snapshots its bits on appearance, cancels when those bits change, and rereads the live binding synchronously in Apply before parsing or writing. Ordinary scalar callers default to `nil` and retain existing behavior.

Existing presentation, displayed-value, locale, range and unit guards remain. Untouched/equivalent input, signed zero, exact SI endpoints, formatting and callbacks are unchanged.

Verification: `git diff --check` passed; agent-cycle structure/check and next completed. Python IEEE-754 reproduction confirms `3.0` and `3.0000000000000004` meters have source bits `4008000000000000` / `4008000000000001`, while both convert to feet bits `4023af5ebd7af5ec`. The new direct source comparison distinguishes that collision, including before an observer receives a view update.

No builds, Swift/native/UI tests, network, commits or additional agents. Root should run the existing native/precision suite. Files are frozen for integration/review.
