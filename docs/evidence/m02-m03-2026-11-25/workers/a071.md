## Fix

`arranged` now evaluates the final positions from the validated original subject,
camera, lights, explicit aims, and the entered destination. It carries the
original coordinate terms through rotation and optional reflection, then rounds
each final affine sum once. It never constructs a rounded displacement,
intermediate world position, or translation offset for final coordinates.

The prior mirror implementation's residual-preserving affine sum was extracted
without altering its algorithm or its existing three-term mirror inputs. The
arrangement path reuses it for arbitrary term counts. Non-cardinal multiplication
also carries its `addingProduct` residual into the final sum. Exact cardinal
rotations and exact axis/diagonal mirror planes use signed coordinate swaps.
There is no epsilon, clamp, or relaxed validation.

The source and completed candidate still undergo full scene validation. Camera
translation and vertical translation use the same final three-term sum; explicit
aims use the same spatial transform as their lights. Subject-following aims remain
implicit and resolve against the exact entered destination. Metadata, IDs,
ordering, photometry, lens, room and preview settings travel unchanged.

Vertical rectangular-emitter roll is reconstructed directly between the original
and completed frames using the combined rotation/reflection direction. The
private helper now accepts the destination subject for the completed frame;
standalone callers keep the default original subject. Reflection's handedness
correction is retained. The existing standalone translation, rotation and mirror
coordinate formulas, validation boundaries, and error behavior are unchanged.

## Independent expectations and regressions

The a068 expression is evaluated over the exact binary input values:

`0.59999999999999 + 99.7 - 0.3 = 100 - 129 * 2^-54`.

At 100 the half-ULP is `128 * 2^-54`, so the correctly rounded answer is
`Double(100).nextDown`, or `99.99999999999999`. For the outside neighbor:

`0.60000000000001 + 99.7 - 0.3 = 100 + 231 * 2^-54`,

which correctly rounds to `Double(100).nextUp` and must reject. These are
independent algebraic expectations, not values copied from the implementation.
Sign reversal gives the corresponding negative-boundary results.

Added regression methods cover:

1. Sixteen algebraically equivalent source arrangements covering all four
   cardinal rotations with no mirror, an axis mirror, and each diagonal mirror.
   Both signs and swapped horizontal axes give 64 valid final arrangements.
   Each also checks genuine outside light/aim rejection and isolates an outside
   stored aim with an otherwise inside light.
2. Fractional camera, light, height and stored-aim translation on all three axes,
   plus independent outside camera rejection for x, y and z, at both signs.
3. Exact halfway results and both neighboring sides with a retained `+/-2^-100`
   tail. Both signs, zero/half turns, light positions and isolated stored aims
   are exercised. These prevent a two-sum approximation from discarding the
   term that determines the final rounding direction.
4. A non-cardinal 3-4-5 rotation, with and without a non-axis camera reflection,
   preserving each actual corner of two non-square overhead rectangles. One
   stores a manual aim; the other follows the moved subject. The independent
   oracle uses the rational matrix rows `(4/5, 3/5), (-3/5, 4/5)` and, after
   mirroring, `(-4/5, 3/5), (3/5, 4/5)`, with `1e-12` geometry tolerance.

## Recurrence prevention

Final-only validation does not guarantee correct composition if each artificial
intermediate world coordinate is rounded. Preserve the original affine terms
through the complete operation and test exact binary rounding thresholds,
including signed counterparts and genuinely outside neighbors.
