## Implemented changes

### `App/StudioPalette.swift` — new shared colors

Added adaptive opaque colors for small text and control labels:

| Color | Light appearance | Dark appearance |
| --- | --- | --- |
| `StudioPalette.action` | #0056B3 | #78B7FF |
| `StudioPalette.secondaryText` | #51545C | #B8BBC3 |
| `StudioPalette.planBackground` | RGB (0.075, 0.085, 0.10) | Same dark plan background |

The original action crops contain #0088FF ink; the original unit crop contains #7F7F7F ink on white. The new light action color calculates to 7.042:1 on white, 6.311:1 on #F2F2F7, and 5.256:1 on the sampled bordered-control background #DEDEE4. New secondary ink calculates to 7.574:1, 6.788:1, and 5.654:1 respectively. Dark scenario calculations also exceed 4.5:1 on black, #1C1C1E, and #2C2C2E. These are sRGB calculations, not runtime audit passes. Inputs and full results are preserved in `contrast-calculation.json`.

### `App/PrecisionValueButton.swift`

- Exact-value readout action now uses `StudioPalette.action`.
- Editor header, unit, explanatory text, and allowed-range footer use opaque `secondaryText`. Header, footer, unit, and Apply use explicit semantic font styles; footer may expand vertically at larger sizes.
- Apply uses the accessible action color; the editor also supplies the same tint to native controls.
- Cancel now has an explicit `Text("Cancel").font(.body)` label, replacing reliance on the toolbar's implicit font.
- Numeric parsing, preserved-value behavior, editing lifecycle, bindings, labels, values, identifiers, and actions are unchanged.

### `App/StudioPlanMarkers.swift`

- Grid title now uses semantic `.caption2.monospaced().weight(.medium)` instead of a fixed-size font constructed from a scaled metric.
- Caption text also uses semantic `.caption2.weight(.semibold)`. The existing scaled caption metric remains for matching layout measurements.
- Grid title uses opaque white and a local opaque plan-background backing.
- Visible displaced captions are now exposed as their own readable text elements, with hit testing still disabled; existing marker actions and their 44-point hit areas remain unchanged.
