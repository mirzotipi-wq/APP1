## Defect and fix

The previous compensated sum preserved the first two addition errors but rounded those errors together before adding them back. For `(100, 2^-47, 2^-100)`, the residual addition loses `2^-100`; the resulting halfway value rounds to `100`. The exact sum rounds to `100.nextUp`, so scene validation should reject the reflection.

The helper now grows an error-free expansion containing every nonzero residual of the three bounded coordinates. It collapses from largest to smallest and retains the remaining term's sign when a rounded addition is halfway. Twice the residual must equal an exact representable step before that final tie correction is applied. Inputs are already validated finite bounded scene coordinates, so this local expansion cannot overflow. Strict existing validation decides acceptance from the correctly rounded result.
