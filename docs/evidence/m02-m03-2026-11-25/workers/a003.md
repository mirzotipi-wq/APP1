## Diagnosis and correction rationale

The trace proves that this control's native touch-end callback precedes all changed native values in the failing run. `finishTracking` retires the token at `end`; `valueChanged` then correctly refuses unowned changes. The model therefore remains 0.6 m. Waiting longer cannot make those already rejected samples become part of the completed edit.

This is a different failure from the historical `38a3b52` test's premature expected-value capture. The completion predicate added in `fb643b1` remains appropriate, but cannot repair a gesture whose model never changes.

Apple's [UISlider documentation](https://developer.apple.com/documentation/uikit/uislider.md), [minimum-track image API](https://developer.apple.com/documentation/uikit/uislider/setminimumtrackimage(_:for:).md), and [maximum-track image API](https://developer.apple.com/documentation/uikit/uislider/setmaximumtrackimage(_:for:).md) document that supplying custom track images disables dynamic slider effects. The documented public customization route provides a concrete correction for a precision control whose edit must finish at the touch boundary. UIKit's exact private animation driver was not inspected; the effect of this route on the reproduced failure still requires the original native UI scenario.

The candidate installs 5-by-4-point rounded track images with two-point horizontal caps, so the center stretches with the slider's width. The minimum track uses the inherited tint; the maximum track uses a semantic system label color. Normal, highlighted, selected, focused, and disabled states receive explicit images. The native thumb is retained. Color updates use `tintColorDidChange` and the public trait-change registration for [system traits affecting color appearance](https://developer.apple.com/documentation/uikit/adapting-your-app-when-traits-change), preserving dynamic light/dark and contrast responses. iOS versions before 26 retain their existing configuration.

The patch adds no timer, deferred commit, global animation setting, private UIKit API, or post-end session reopening. It does not change history semantics or persistence. It leaves the model-derived accessibility label/value and 44-point minimum target intact. All callers continue to share the same slider component.
