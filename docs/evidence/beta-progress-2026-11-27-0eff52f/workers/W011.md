## Service source review

Refresh publication checks a revision token and cancellation after suspension; stale reads restart. The verified-transaction handler uses a separate finite task to finish reconciliation even if the purchase-view task is cancelled. Current entitlement is published before approval resolution, and transaction finishing is deduplicated while in flight.
