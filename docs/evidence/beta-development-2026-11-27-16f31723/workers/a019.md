## Findings

**Ordinary close is protected.** `ProjectLibraryView.swift:194` stops admission and cancels an uncommitted read before Done dismisses. `219–222` does the same on disappearance when the file picker is not covering Projects. A read result additionally checks cancellation, request identity, admission and source-scene equality (`448–450`). A project switch invalidates the captured parent generation, so `StudioSession.beginLibraryOperation` / `ProjectLibraryOperationState.reserve` reject that old callback.

**Conditional terminal-teardown gap remains.** Disappearance deliberately does nothing while `showImporter` is true, preserving the legitimate picker-cover case. There is no terminal-removal hook or closed-presentation receipt. Thus, if a successful picker callback is delivered after parent/window removal, `acceptingImports` can remain true and `importSelection` can reach the create reservation (`411–455`). Removing a `WindowGroup` window does not itself invalidate `StudioSession.generation`; its admission checks cover project identity, loaded/clean state and busy state, not presentation lifetime. This is a source-level admission gap, **not a reproduced native callback-after-removal failure**. No change is recommended as a release blocker on this evidence alone.

A narrow hardening option is terminal owner cleanup that sets admission false and cancels only the precommit read, without treating temporary picker covering as closure. Keep the accepted-commit boundary intact: `cancelImport` intentionally returns once `isCommittingImport` is true, while the session retains and adopts its committed operation even after the sheet observer disappears.

**File-reader cancellation is coherent.** `ProjectDocumentIO.read` forwards cancellation to both the detached worker and `NSFileCoordinator`, checks before/after decoding and delivery, and releases security-scoped access with `defer`. Existing native tests cover cancellation before reading, while coordination waits, and committed-save receipt adoption; they were inspected, not executed.
