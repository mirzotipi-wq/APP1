# A011 — adaptive PDF export controls

Baseline: `a01fa08` (private detached worktree). Scope: only `App/LightingPlanExportView.swift`.

The original export screen put two pickers in one horizontal row, then put a flexible PDF preview, page summary, Share action and privacy explanation in a non-scrolling vertical stack. Larger text or a short window could squeeze the preview while leaving no scrolling escape for the controls.

The candidate stacks the paper/unit menus at accessibility text sizes, and also falls back to a vertical arrangement when the horizontal option does not fit. Pickers retain their existing accessibility identifiers and have a 44-point minimum height.

Options, page summary, Share and failure/retry feedback now live in a separate control region. Its height is bounded to 45% of the available content height; a vertical fit check uses natural layout when possible and a scroll view when content needs more room. The PDF remains outside that scroll view, preserving its independent page scrolling. Done stays in the navigation toolbar. Failure feedback and Retry have the same scrolling escape as the normal controls.

The immutable scene/name snapshot, options identity, prepared-document identity checks, cancellation checks and main-actor PDF renderer are unchanged. Existing page-summary, Share, preview, paper, units and Done identifiers remain. No tests, timing bounds, source fixtures or gate definitions changed.

Checks actually run: source review of the existing export UI tests and all affected identifiers; `python3 scripts/agent_cycle.py check` (valid structure, not release proof); `python3 scripts/agent_cycle.py next` (M01 remains active); `git diff --check` (passed). No Swift compiler/Xcode exists here. Native build, Default/AXXXL screenshots, narrow-window picker containment, scroll/retry/Share interactions and PDF page navigation remain unrun and must be verified on Apple platforms.

No native test was added for this bounded layout change. Root owns independent review, integration, canonical status and native validation.
