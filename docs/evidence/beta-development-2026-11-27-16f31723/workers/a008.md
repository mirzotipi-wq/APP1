## Change

Changed only `App/ARPlacementView.swift`. The nested manual-sheet presentation binding now accepts dismissal writes only. The explicit manual action still creates a fresh UUID and opens the sheet.

Previously, Done or a false binding write could retire `showingManual` while leaving `manualOwner` alive until the dismissal callback. A later true write for that same owner could restore `showingManual`, reopen the retired sheet, and re-enable its guarded room callbacks. The binding now rejects true writes, matching the outer feature-sheet ownership contract. Old-owner dismissal remains rejected and fresh manual openings remain unchanged.

This is a source-proven state-transition gap, not an observed physical-device reproduction.
