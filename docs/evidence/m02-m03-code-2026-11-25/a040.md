## Findings

- `PrecisionValueEditor` snapshots displayed/source bits, locale, range and initial text on appearance. Untouched Apply bypasses parsing and writing, including the empty scientific-value preservation draft. Equivalent parsed values also avoid writing, preserving signed zero.
- Invalid Apply leaves the editor active and the source untouched. A subsequent draft change clears the error; valid Apply can proceed. Cancel clears `active` before dismissal and never invokes the value setter. Successful Apply clears `active` before its single setter call, rejecting duplicate submissions.
- Source checks read both live bindings, protecting SI changes hidden by display conversion. Observers cancel on source, locale or range changes. Distance unit changes replace view identity; the conversion setter independently rejects obsolete units. Studio bindings additionally reject retired project generations and capture light identity.
- Distance endpoint edits map to original SI bounds before validation. Ordinary edits are neither clamped nor snapped. Studio setters record one prior scene when no gesture is active; gesture history has separate ownership.
