## Implementation

Default budget is 580 seconds inside the unchanged ten-minute step; finite overrides are capped at 600. First attempt receives half the working budget; preflight, recovery, second attempt, readiness verification and owned-process cleanup share one monotonic deadline.

One target-only shutdown/reboot is permitted after startup failure on a GitHub-hosted ephemeral runner. UDID, runtime, device type and availability are revalidated. Success requires bootstatus exit zero and a subsequent exact-device Booted inventory before deadline. Cancellation, malformed metadata, identity changes and failed cleanup are terminal. No erase, global reset, test execution, test retry or deadline increase occurs. Separate raw streams, command receipts and an incremental report preserve both attempts and errors without overwriting earlier evidence.
