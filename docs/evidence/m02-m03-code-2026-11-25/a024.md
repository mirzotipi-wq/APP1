## Source findings

`ReferencePNG.swift` is a metadata-chunk filter, **not an RGBA PNG encoder**. It contains no dimension/RGBA-count validation, scanline generation, CRC construction or Adler construction. This matches its documented contract and ImageIO-encoded caller in `App/ReferencePhoto.swift`.

On supported 64-bit targets, the four-byte chunk length fits `Int`; the remaining-byte guard bounds `offset + 12 + length` before addition. Signature, first/unique 13-byte IHDR, nonempty IDAT, terminal zero-length IEND, trailing data, critical chunks and total input size are checked. Retained CRC bytes are preserved without validation. `ReferencePNGTests.swift` deliberately uses zero dimensions/CRCs and synthetic IDAT: these tests establish framing/filter behavior, not decodability. No blocking defect found within this trust contract; encoder-construction review is inapplicable.
