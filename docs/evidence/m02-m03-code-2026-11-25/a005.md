## Observed defect and implementation

The Study preview previously keyed its SwiftUI task only by its normalized scene/subject request. Going inactive or entering the background did not change that identity, so the view could continue debounced CPU work or backend validation after the scene stopped being active.

The view now reads `scenePhase` and derives an optional `activeRequest`: the existing request while active, otherwise `nil`. The SwiftUI task uses that optional identity and returns immediately for `nil`. Moving away from active therefore cancels the previous task through the existing SwiftUI-managed task lifecycle. Changes between inactive and background, or scene edits while inactive, keep the identity `nil` and submit no new render. Returning to active supplies the latest normalized scene/subject request.

The completed `Frame` state is retained. Returning to the same successfully rendered request takes the existing early-return path, preserving its image without another render. A changed request retains the current previous-frame behavior: only a valid image of the same subject may remain visible while replacement work runs. An old error or another subject cannot stand in for the current request. Failed frames remain retryable on a new active task.

The existing 80 ms debounce and cancellation paths remain intact. A cancelled sleep returns without rendering. `StudyRenderEngine` observes task cancellation during CPU/validation work and before cache admission; its existing backend routing/cache rules are unchanged. The preview checks task cancellation after the render, after CGImage creation and before error publication. Submitted GPU commands can finish under the existing engine policy, but cancelled results are discarded. This change does not claim that a submitted GPU command is forcibly stopped.

No separate request comparison was added inside the asynchronous closure: comparing immutable view values captured by that same closure would not establish freshness. SwiftUI's task-identity cancellation and the existing cancellation checks supply that protection.
