## Ideal photometry

Point model: E = I max(0, cos(theta)) / r^2 in lux. Tests cover 0, 30, 60, 90, 120 and 180 degrees; expected absolute tolerance 1e-9 lux, inverse square, invalid intensity and coincident points. The rectangle uses a 32x32 midpoint grid and one-sided, uniform Lambertian luminance: E = L cos(emission) cos(incidence) dA / r^2. Coordinates are meters; I is on-axis far-field cd, L = I / area in cd/m^2. Rectangle dimensions 0.05–4 m, intensity 0–100000 cd, orthogonal axes; minimum plane distance max(0.05 m, longest side/4). Returns nil for unsupported near-plane geometry, zero for supported back-facing configurations. No occlusion, reflections, transmission, nonuniform light distributions, spectral effects, device or material calibration.

References for model: [PBRT 4e radiometry](https://pbr-book.org/4ed/Radiometry%2C_Spectra%2C_and_Color/Radiometry) and [radiometric integrals](https://pbr-book.org/4ed/Radiometry%2C_Spectra%2C_and_Color/Working_with_Radiometric_Integrals). Parallel test reference is derived analytically from the projected solid angle of a centered rectangle; offset reference uses separate composite Simpson integration with 160 intervals per axis. Both use 1000 cd.
